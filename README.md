# Salivary gland organoids review revision

Public revision materials for the review manuscript “Salivary gland organoids: from biological complexity to precision medicine and regeneration.”

## Files

- `Salivary-gland-organoids-review-revised.docx` — revised manuscript, with tracked changes accepted and editorial comments removed.
- `Response-to-reviewers.docx` — response letter, with tracked changes accepted and editorial comments removed.

The response letter contains reviewer comments. The manuscript and response letter identify the authors and their affiliations.
