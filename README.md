# Salivary gland organoids review revision

Public revision materials for the review manuscript “Salivary gland organoids: from biological complexity to precision medicine and regeneration.”

## Read online

- [Revised manuscript PDF](Salivary-gland-organoids-review-revised.pdf) — page-by-page reading and printing.
- [Revised manuscript plain text](Salivary-gland-organoids-review-revised.txt) — complete text with page breaks, suitable for searching and screen readers.
- [Response letter PDF](Response-to-reviewers.pdf)
- [Response letter plain text](Response-to-reviewers.txt)

## Editable files

- [Revised manuscript DOCX](Salivary-gland-organoids-review-revised.docx)
- [Response letter DOCX](Response-to-reviewers.docx)

The DOCX files have tracked changes accepted and editorial comments removed. The response letter contains reviewer comments. The manuscript and response letter identify the authors and their affiliations.
